# Dashboard Analítico P&L y KPIs

Aplicación web interactiva (100% en navegador) para análisis financiero de P&L, árbol jerárquico de cuentas y evaluación de Unit Economics.

- **Uso:** Abre la página de GitHub Pages y carga tus archivos locales de Excel (`1A. Balance P&G` y `1B. Tickets TKT`). Ningún dato se envía a servidores externos; todo se procesa localmente en la memoria de tu navegador.
